# social-media
a social media web (facebook style)
built on nodejs, express, mysql and react

you can do multiply actions, such as:
- register and login
- edit your profile (change image or name)
- upload posts
- follow other users
- approve others to follow you
- see their posts on your feed
- see their stories
- add comments to the posts
- like some posts/comments
- search other users
- upload a story (and delete)
- see your story history
- send messages to friends (starts chats, and group chats)
- send a message via story
- play some small games and see the top 5 of your friends (vibe-coded)
and many more features!
